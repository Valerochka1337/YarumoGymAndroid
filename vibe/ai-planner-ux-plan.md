# UX AI-планировщика

База: origin/main a20a77b, ветка feat/ai-planner-ux. Основной агент — интеграция,
упражнения и проверки; один независимый исполнитель — дата/время и восстановление.
Существующие PlanningChoiceSheet/PlanningDateTimeFields уже решают часть исходной проблемы.
Библиотека RoutineEditor — отдельный навигационный каталог; сохраняем компактную общую
шторку планирования, узко переиспользуем типизированные поля подходов редактора программы.

- AC-001 / T-001: форма исключений содержит только выбранные строки с удалением;
  добавление через общий поиск, без дублей, отмена без изменений.
- AC-002 / T-002: редактор содержит только план, явную замену через поиск;
  доступность по залам, типовые поля и очистка несовместимых значений; сохранение порядка.
- AC-003 / T-003: общий date/time picker без поля timezone, автоматическая зона устройства,
  сохранение момента при восстановлении, корректные DST gap/overlap и будущая дата.
- AC-004 / T-004: локальные черновики и явное подтверждение сохраняются; enqueue,
  offline-очередь, owner/generation guards и backend контракт остаются прежними.
- AC-005 / T-005: адресные unit/Compose semantics регрессии, compact/fontScale2,
  форматирование; на стабильном diff полный testDebugUnitTest и assembleDebug.
- T-006: один patch/versionCode относительно актуального main, локальный APK и отчёт.

Без публикации, релиза, телефона, реальных AI-запросов и скриншотов.
