# Полный перенос Live Coach на сервер

Цель: сервер управляет инициативой, расчётами, диалоговой историей и памятью решений;
Android доставляет снимки, читает постоянный SSE и применяет подтверждённые предложения через WorkoutEditor.

1. Расширить существующие coach_runs/session outbox без второго механизма исполнения.
2. Добавить атомарные messages, server semantic state, receipts с причиной/фактами и model-check.
3. Сохранить историю событий на тренировку, непрерывный SSE и origin, проверку свежести 120 с.
4. Перевести Android на новый API, независимые доставку/SSE, окно 1 с, heartbeat 60 с,
   транзакционный курсор/черновик/результат, UI только USER progress, скрытую инициативу.
5. PostgreSQL 022 и Room 34→35 без потери данных; Android 1.3.74 (82), один инкремент.
6. Проверить PostgreSQL-интеграцию, backend check/bootJar, Android unit tests/assembleDebug,
   playground, обновить документацию. Совместимый backend выпускается первым; публикация вне задачи.
