# Changelog

## [Unreleased]

## [1.3.82] — 2026-09-21

### Добавлено

- Общие акценты упражнений в админке задают настройки AI-планировщика по умолчанию.
- Личные акценты переопределяют общие настройки для выбранных упражнений, включая явный
  «Обычный» режим. Удаление личного выбора возвращает настройку по умолчанию.

### Изменено

- В профиле показываются только личные переопределения; упражнения добавляются через поиск
  с выбором акцента.

## [1.3.80] — 2026-09-21

### Изменено

- AI-планирование показывает список предложений и одну нижнюю кнопку «Составить с ИИ».
- Просмотр и редактирование предложенной тренировки используют общие компоненты с программами.
- Статусы предложений и отдельное действие переноса даты убраны; дата меняется через «Изменить план».
- Предложения можно удалять из списка, повторно сохранять в тренировки и применять к календарю.
- Применение блокируется при пересечении с запланированной тренировкой; причина видна внутри кнопки.

## [1.3.79] — 2026-09-20

### Исправлено

- В AI-планировании убраны кнопки «Из программы» и обновления в шапке.
- Предложения используют локальное состояние при повторном открытии и обновляются при
  изменении данных.
- Системная кнопка Back из подразделов настроек возвращает к корневым плиткам.
- При AI-перерасчёте кнопки переносятся целиком, сохраняя однострочную подпись «Изменить условия».
- Открытый экран продолжает получать статус долгого AI-расчёта после первых двух минут.
- Личные программы редактируются прямо из меню; удаление учитывает связанные планы календаря и сохраняет историю.
- Запуск готовой программы сохраняет её подходы и цели вместо перезаписи значениями прошлой тренировки.
- Предыдущие AI-предложения можно сохранить в тренировки или запланировать на новую дату.

## [1.3.77] — 2026-09-20

### Добавлено

- AI-планировщик использует редактируемые коллекции тренировок по целям и сводку нагрузки
  по мышцам. Серверные настройки паттернов и модели доступны в админке.
- Вес рассчитывается отдельно по фактической истории упражнения; без подходящих результатов
  он остаётся незаполненным.

### Изменено

- Акценты упражнений для всех целей объединены в компактный редактор профиля.
- Выбор оборудования убран из профиля: планировщик использует оснащение выбранных залов.

## [1.3.76] — 2026-09-19

### Добавлено

- Агентное AI-планирование формирует программу из ограниченного проверяемого набора упражнений
  с учётом профиля, доступного оборудования и истории тренировок.
- Для упражнений доступны предпочтения «чаще», «реже» и «никогда», которые синхронизируются
  между устройствами и учитываются при подготовке плана.
- Ожидающее AI-предложение можно уточнить текстовым пожеланием; результат создаёт новую версию
  черновика и по-прежнему требует отдельного подтверждения.

### Исправлено

- Экран профиля и аккаунта совместил обновлённые выбор даты рождения и оборудования с новыми
  настройками AI-планировщика.

## [1.3.75] — 2026-09-19

### Изменено

- Обновлены настройки профиля и тренировки, выбор даты рождения и оборудования; интеграция с
  Google Calendar удалена.

## [1.2.4] — 2026-08-31

### Исправлено

- Установка обновлений переведена на системные `PackageInstaller.Session`: проверенный APK
  передаётся Android напрямую, поэтому ColorOS/OxygenOS больше не теряет доступ к файлу между
  внутренними экранами установщика и не показывает ложную ошибку разбора пакета.
- Блокировка, отмена и другие ответы защиты устройства обрабатываются отдельно и показываются
  пользователю понятными сообщениями без внутренних кодов Android.

## [1.2.0] — 2026-08-30

### Добавлено

- Безопасное обновление из GitHub Releases: release-сборка тихо проверяет новую стабильную
  версию при запуске, предлагает обновиться, позволяет отложить запрос один раз или скрыть
  конкретную версию, а экран настроек показывает текущую версию и состояние обновления.
  APK скачивается с прогрессом и до системной установки проверяется по GitHub SHA-256,
  package name, `versionName`, более высокому `versionCode` и release-подписи.
- GitHub Actions автоматически публикует новый подписанный APK и checksum как GitHub Release,
  когда на `main` впервые появляется новый `versionName`; существующий тег не перезаписывается.
- Восстановление из Google Sheets теперь охватывает InBody-замеры и пользовательские программы:
  замеры дедуплицируются по UUID, программы хранятся в append-only листе `Routines` со снимками,
  версиями и tombstone удаления. После входа импорт запускается автоматически, если ID таблицы
  вернулся из резервной копии.
- Отдельная карточка упражнения с картой вовлечения мышц, кнопкой редактирования, результатом
  прошлого раза, интерактивным графиком и рекордами. Она открывается из активной тренировки,
  редактора программы, истории, итогов, аналитики и по info-кнопке библиотечного пикера;
  метрики адаптированы для силовых, упражнений на время и кардио.
- ИИ-создание упражнения и распознавание InBody через настраиваемый OpenAI-совместимый API:
  HTTP(S) base URL с автоматическим API-префиксом `/v1`, авторизованный каталог `/v1/models` и
  единый выбор chat-модели для обоих сценариев. Ручное создание упражнения сохраняется как fallback.
- Настройка API key: AES/GCM через Android Keystore, отдельный DataStore и исключение
  нового и прежнего секретов из cloud backup/device transfer.

### Исправлено

- Длительные запросы генерации и распознавания фото используют отдельные увеличенные таймауты,
  не меняя короткое ожидание каталога моделей и остальных сетевых операций.
- `finish_reason: length` теперь показывается понятной ошибкой вместо «неполного ответа», а
  генерация упражнения и распознавание InBody получили запас в 2048 токенов на полный JSON.
- Системные промпты создания упражнения и распознавания InBody явно задают короткий режим работы:
  минимум рассуждений, без пошагового анализа и лишних перепроверок, затем сразу JSON.
- Схема существующего упражнения теперь обязательно требует `existingExerciseId`; неиспользуемые
  поля второй ветки имеют значение `null`, поэтому модель не может вернуть только `kind=existing`.
- Ошибки upstream-а, которые совместимый API возвращает внутри HTTP 200, теперь
  распознаются и показываются понятным сообщением с возможностью повторить запрос.
- При недоступности выбранной модели ИИ-форма сразу предлагает открыть настройки и сменить её.
- Усилен контракт генерации: точная JSON Schema передаётся в системной инструкции при
  `response_format=json_object`; изолированные JSON-данные каталога и терпимая обработка
  неиспользуемых полей выбранной ветки уменьшают число ложных ошибок разбора ответа.

## [1.1.0] — 2026-08-02

Финальная полировка до «AAA»-уровня.

### Добавлено

- Единые моушн-токены `GymMotion` (пружины Material 3 Expressive) и анимации по всему
  приложению: графики анимируют данные (столбцы вырастают, линия прочерчивается, метка
  ZoneMeter скользит), сетка календаря слайдится в сторону свайпа, списки анимируют
  перестановки (`animateItem`), чипы и рамки выделения переезжают цветом, статус выгрузки
  меняется через fade+scale, контент после загрузки проявляется (`FadeInContent`).
- Семантический тактильный отклик `GymHaptics`: выполнение/отмена подхода, шаги веса и
  повторов (long-press мягче), рест-пилюля, завершение/отмена тренировки, вкладки, выбор
  программы, тап по мышце, появление рекордов. Выключается настройкой «Виброотклик».
- Настройки: автостарт таймера отдыха после подхода; секция «Данные» — экспорт базы
  (SQLite-копия через системный диалог), полная очистка истории с подтверждением,
  «О приложении» с версией.
- Импорт из Google Sheets сообщает о нераспознанных строках вместо молчаливого пропуска.
- Рабочая release-сборка: R8 + сжатие ресурсов (APK ~5 МБ), keep-правила kotlinx-serialization.
- Документация: ARCHITECTURE.md, CLAUDE.md, CHANGELOG.md; обновлены README и design-system
  (секции «Моторика» и «Хаптика»).

### Исправлено

- Фон окна при запуске совпадает с фоном темы (убрана цветовая «ступенька» первого кадра).
- Отмена импорта больше не маскируется под ошибку (`CancellationException` пробрасывается).
- Пересчёт аналитики ушёл с главного потока; карта тела не разбирает SVG заново при каждом
  перевороте и возврате на экран; уведомление тренировки пересобирается один раз на изменение.

### Изменено

- Правила бэкапа заданы явно (полный бэкап включён: токенов в данных нет).
- Удалён мёртвый код DAO, дубли `classifyHttp` и сортировки дерева тренировки.
- 91 новый unit-тест (434 всего): воркер выгрузки, ActiveWorkoutViewModel, форматтеры,
  доменные формулы, экспорт базы, хаптика, иконки лаунчера.

## [1.0] — 2026-08-01

Первый полный релиз: программы тренировок, библиотека упражнений с картой вовлечения мышц,
активная тренировка с таймером отдыха и Live-уведомлением, календарь с планированием
(ad-hoc и недельное расписание + Google Calendar), аналитика нагрузки (тепловая карта тела,
объёмы, баланс, прогресс 1ПМ), выгрузка и импорт Google Sheets, выбор акцента с иконкой
лаунчера.
